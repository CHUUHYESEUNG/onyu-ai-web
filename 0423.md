     2. 오디오 품질 vs 파일 크기 최적화

     | 비트레이트    | 10분 파일 크기 | 품질  | STT 정확도 | 추천
     |
     |----------|-----------|-----|---------|-------|
     | 32 kbps  | ~2.4 MB   | 낮음  | 90%     | ❌     |
     | 64 kbps  | ~4.8 MB   | 중간  | 95%     | ✅ MVP |
     | 128 kbps | ~9.6 MB   | 높음  | 98%     | ✅ 확장  |
     | 256 kbps | ~19.2 MB  | 최고  | 99%     | ❌ 과함  |

     추천: 64 kbps (MVP), 128 kbps (사용자 선택 옵션)

     3. 파일 업로드 전략 비교

     옵션 A: Supabase Storage → Deepgram (추천)

     녹음 완료 → Supabase Storage 업로드 → DB에 메타데이터 저장
     → Route Handler가 Storage에서 다운로드 → Deepgram 전송
     → 전사 결과 DB 업데이트
     장점:
     - 원본 파일 백업 (재처리 가능)
     - 네트워크 실패 시 재시도 용이
     - 향후 다른 STT 서비스로 전환 시 유리

     단점:
     - 이중 업로드 (브라우저→Supabase, Supabase→Deepgram)
     - 처리 시간 약간 증가 (~2-3초)

     옵션 B: 직접 Deepgram 전송

     녹음 완료 → FormData로 Route Handler 전송 → Deepgram 전송
     → 성공 시 Supabase Storage에 백업
     장점:
     - 빠른 처리
     - 단일 업로드

     단점:
     - 네트워크 실패 시 재녹음 필요
     - 원본 파일 백업 누락 위험

     최종 추천: 옵션 A (안정성 우선)

     4. Vercel Functions 타임아웃 대응

     제약:
     - Vercel Hobby: 10초
     - Vercel Pro: 60초 (API Routes), 300초 (Edge Functions)
     - Deepgram 처리 시간: 10분 오디오 = 약 30-60초

     해결 방법:

     옵션 1: 비동기 처리 (추천)

     브라우저 → API Route (즉시 응답) → DB에 job 등록
     → Background 처리 (Next.js Cron 또는 별도 워커)
     → Supabase Realtime으로 진행 상황 푸시

     옵션 2: 클라이언트 직접 호출 (간단)

     브라우저 → Deepgram API 직접 호출 (NEXT_PUBLIC_DEEPGRAM_API_KEY
     사용)
     → 결과를 DB에 저장
     주의: API 키 노출 (공개 프로젝트면 위험)

     옵션 3: 청크 분할

     10분 오디오 → 2분씩 5개 청크 분할
     → 각 청크를 순차 처리 (각 30초 이내)
     → 결과 병합

       private mediaRecorder: MediaRecorder | null = null;
       private audioChunks: Blob[] = [];
       private stream: MediaStream | null = null;

       // 1. 마이크 권한 요청 및 스트림 획득
       async requestPermission(): Promise<void> {
         try {
           this.stream = await navigator.mediaDevices.getUserMedia({
             audio: {
               echoCancellation: true,  // 에코 제거
               noiseSuppression: true,  // 노이즈 제거
               sampleRate: 44100,       // CD 품질
             }
           });
         } catch (err) {
           throw new Error('마이크 권한이 거부되었습니다');
         }
       }

       // 2. 녹음 시작 (Safari 호환 코덱 자동 선택)
       start(): void {
         // Safari: MP4, 기타: WebM
         const mimeType = MediaRecorder.isTypeSupported('audio/webm')
           ? 'audio/webm;codecs=opus'
           : 'audio/mp4';

         this.mediaRecorder = new MediaRecorder(this.stream!, {
           mimeType,
           audioBitsPerSecond: 64000, // 64 kbps
         });

         this.mediaRecorder.ondataavailable = (e) => {
           this.audioChunks.push(e.data);
         };

         this.mediaRecorder.start(1000); // 1초마다 데이터 수집
       }

       // 3. 녹음 정지 및 Blob 반환
       stop(): Promise<Blob> {
         return new Promise((resolve) => {
           this.mediaRecorder!.onstop = () => {
             const blob = new Blob(this.audioChunks, {
               type: this.mediaRecorder!.mimeType
             });
             this.audioChunks = [];
             resolve(blob);
           };
           this.mediaRecorder!.stop();
           this.stream?.getTracks().forEach(track => track.stop());
         });
       }

         // mediaRecorder.state === 'recording' 시 경과 시간 반환

     export function useAudioRecorder() {
       const [isRecording, setIsRecording] = useState(false);
       const [isPaused, setIsPaused] = useState(false);
       const [duration, setDuration] = useState(0); // 초 단위
       const [audioBlob, setAudioBlob] = useState<Blob | null>(null);
       const [error, setError] = useState<string | null>(null);

       const recorderRef = useRef<AudioRecorder | null>(null);
       const intervalRef = useRef<NodeJS.Timeout | null>(null);

       const startRecording = async () => {
         try {
           const recorder = new AudioRecorder();
           await recorder.requestPermission();
           recorder.start();

           recorderRef.current = recorder;
           setIsRecording(true);
           setError(null);

           // 1초마다 duration 업데이트
           intervalRef.current = setInterval(() => {
             setDuration(prev => prev + 1);
           }, 1000);

         } catch (err) {
           setError('녹음을 시작할 수 없습니다. 마이크 권한을
     확인해주세요.');
         }
       };

       const stopRecording = async () => {
         if (!recorderRef.current) return;

         const blob = await recorderRef.current.stop();
         setAudioBlob(blob);
         setIsRecording(false);

         if (intervalRef.current) {
           clearInterval(intervalRef.current);
         }

         return blob;
       };

       const pauseRecording = () => {
         recorderRef.current?.pause();
         setIsPaused(true);
         if (intervalRef.current) clearInterval(intervalRef.current);
       };

       const resumeRecording = () => {
         recorderRef.current?.resume();
         setIsPaused(false);
         // interval 재시작
       };

       // 컴포넌트 언마운트 시 정리
       useEffect(() => {
         return () => {
           if (recorderRef.current) {
             recorderRef.current.stop();
           }
           if (intervalRef.current) {
             clearInterval(intervalRef.current);
           }
         };
       }, []);

       return {
         isRecording,
         isPaused,
         duration,
         audioBlob,
         error,
         startRecording,
         stopRecording,
         pauseRecording,
         resumeRecording,
       };
     }

     import { NextRequest, NextResponse } from 'next/server';
     import { supabase } from '@/lib/supabase';

     export async function POST(request: NextRequest) {
       try {
         const formData = await request.formData();
         const audioFile = formData.get('audio') as File;
         const assetId = formData.get('assetId') as string;

         if (!audioFile || !assetId) {
           return NextResponse.json(
             { error: 'Missing audio file or asset ID' },
             { status: 400 }
           );
         }

         // 1. Deepgram API 호출
         const response = await fetch(
           'https://api.deepgram.com/v1/listen?language=ko&model=nova
     -2&punctuate=true&diarize=false',
           {
             method: 'POST',
             headers: {
               'Authorization': `Token
     ${process.env.NEXT_PUBLIC_DEEPGRAM_API_KEY}`,
               'Content-Type': audioFile.type,
             },
             body: await audioFile.arrayBuffer(),
           }
         );

         if (!response.ok) {
           throw new Error(`Deepgram API error:
     ${response.statusText}`);
         }

         const data = await response.json();
         const transcript =
     data.results.channels[0].alternatives[0].transcript;
         const confidence =
     data.results.channels[0].alternatives[0].confidence;

         // 2. DB 업데이트
         await supabase.from('audio_assets').update({
           status: 'transcribed',
           transcript: transcript,
           progress: 100,
         }).eq('id', assetId);

         return NextResponse.json({
           transcript,
           confidence,
         });

       } catch (error) {
         console.error('Transcription error:', error);

         // DB 에러 상태 업데이트
         const assetId = (await request.formData()).get('assetId') as
      string;
         if (assetId) {
           await supabase.from('audio_assets').update({
             status: 'failed',
             error_message: error instanceof Error ? error.message :
     'Unknown error',
           }).eq('id', assetId);
         }

         return NextResponse.json(
           { error: '음성 변환에 실패했습니다. 다시 시도해주세요.' },
           { status: 500 }
         );
       }
     }
